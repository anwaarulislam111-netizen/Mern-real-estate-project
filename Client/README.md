# PakEstate Client

The PakEstate client is a React and Vite application for browsing, searching, and managing property listings.

## Development

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

Set `VITE_BACKEND_URL` in `Client/.env` to the URL of the running API server.
